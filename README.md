# OOP Calculator (C++)

A console-based Calculator application developed in C++ using Object-Oriented Programming (OOP). The project demonstrates encapsulation, class design, and basic arithmetic operations through a reusable calculator class.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear calculator
- Cancel last operation
- Display calculation results

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Classes and Objects
- Encapsulation

## How to Compile and Run

```bash
g++ -std=c++17 moh.cpp -o Calculator
./Calculator
```

## Learning Objectives

This project was developed to practice:

- Object-Oriented Programming (OOP)
- Class design
- Encapsulation
- Member functions
- Problem-solving using C++
